# 已确认硬件

本文只记录经过资料交叉检查或实机验证的事实。不要用外观相似的通用 Waveshare 接线覆盖这些结论。

## 主控与屏幕

- 主控模块：ESP32-WROOM-32E；
- Flash：8 MB；
- PSRAM：无；
- USB 转串口：CH340C；
- 屏幕：7.5 英寸、800×480、黑/白/红三色；
- 屏幕排线标记：`P750057-MF1-A`；
- 已验证兼容驱动：GxEPD2 的 `GxEPD2_750c_Z08`；
- EPD SPI：mode 0，4 MHz；
- 实机一次全刷约 21 秒。

PCB 背面没有元件。设备最终观察方向下，USB-C、开关和按键全部在右侧。

## 引脚表

| 功能 | GPIO | 说明 |
|---|---:|---|
| EPD SCK | 18 | SPI 时钟 |
| EPD MOSI | 23 | SPI 数据 |
| EPD CS | 5 | 片选；启动绑带脚，启动后尽早拉 HIGH |
| EPD DC | 19 | 数据/命令 |
| EPD RST | 16 | 屏幕复位 |
| EPD BUSY | 17 | 屏幕忙信号 |
| I²C SDA | 21 | SHT30 |
| I²C SCL | 22 | SHT30 |
| 外设门控 | 25 | SHT30 低侧地与电池分压共同使能 |
| 电池 ADC | 36 | 标称 10k/10k 分压 |
| Upper | 34 | 输入专用，板载上拉，低有效 |
| Middle | 35 | 输入专用，板载上拉，低有效 |
| Lower | 39 | 输入专用，板载上拉，低有效 |

SHT30 地址为 `0x44`。EPD BUSY 低有效，空闲正常为 HIGH。

GPIO34/35/39 不支持内部上拉，必须使用板上已有的 10k 上拉；代码中不要配置 `INPUT_PULLUP`。GPIO0 连接 CH340 自动下载控制，不属于用户按键。

## 右侧物理顺序和按键语义

从上到下：

1. USB-C；
2. 电源开关；
3. EN/硬件复位；
4. Upper / GPIO34；
5. Middle / GPIO35；
6. Lower / GPIO39。

短按：Upper 下一页、Middle 请求刷新、Lower 返回。长按：Upper 立即轮询 Bridge、Middle 进入 System、Lower 回首页。

## GPIO25 注意事项

GPIO25 不是整机电源保持信号。它同时控制 SHT30 的低侧地路径和电池采样分压。正常状态必须保持 LOW；采样前短暂拉高，完成后立即恢复 LOW。长期拉高会带来无意义耗电，也可能改变传感器/分压网络行为。

采样完成并拉低 GPIO25 后，I²C 引脚按现有实现切回输入，避免通过 SDA/SCL 向已经断开低侧地的传感器反向供电。

## 电池

板上没有已确认的电量计 IC，因此百分比只能根据 GPIO36 电压估算。当前按 2:1 分压和保守锂电曲线换算，界面必须用 `~NN%` 表示“约”。在完成万用表标定、电池化学体系确认、充放电曲线和低压保护测试前，不应把该百分比用于关机策略。

充电芯片的 CHRG#/STDBY# 只驱动板上红/绿 LED，没有连接 ESP32 GPIO，因此固件无法可靠读取“正在充电”或“已充满”。照片中 `8025` 外置 RTC 位号未焊，固件也不能依赖外置 RTC。

## Flash 布局

| 区域 | 偏移 | 说明 |
|---|---:|---|
| bootloader | `0x1000` | 禁止普通开发写入 |
| partition table | `0x8000` | 禁止普通开发写入 |
| NVS | `0x9000` | 保存 Wi-Fi 等私密配置 |
| OTA data | `0xE000` | 禁止普通开发写入 |
| app0 | `0x10000` | 唯一允许更新的应用分区 |
| app1 | `0x260000` | 保留原始回退应用 |
| SPIFFS | `0x4B0000` | 保留原设备数据 |

app0 大小为 `0x250000` 字节。详细规则见 [`FLASH_SAFETY.md`](FLASH_SAFETY.md)。

屏幕刷新时板上会产生正负高压，不要带电触碰或短接电荷泵区域。如果刷新中按 EN 或发生掉电，启动时 BUSY 可能保持 LOW；必须继续使用现有的 `Unknown -> 一次恢复 -> FaultLocked` 有界流程，不能无限复位或无限重试。

## 仍需实机确认

- ADC 与真实电池电压的校准系数；
- SHT30 在 USB/充电热源稳定后的偏差；
- EN 在屏幕刷新中断时的恢复；
- BUSY 故障时高压轨是否可靠关断；
- 待机/刷新/联网功耗、低压截止和续航。
